# Handy Minigames demo
an android game with 5 little mini games that revolve around an ai hand tracker

## how does it work
it works by using two Mediapipe models trained by google one to detect where the palm is and give me a bounding box around it
and the other just scales that bounding box to fit the whole hand before tracking 21 landmarks on the hand shown in this image
<img width="1543" height="538" alt="image" src="https://github.com/user-attachments/assets/4e45b5f9-69dd-4eb3-841d-7f2420c2f892" />

## how to play
you need an android to be able to play the game you can download it from [it's itch page](https://cof99.itch.io/handy-minigames)
